---

## 🚀 Sobre o Projeto

Este aplicativo foi desenvolvido para otimizar o atendimento de balcão e a gestão de inventário de uma loja **Frutos de Goiás**. A aplicação roda de forma totalmente offline utilizando Python e uma interface web moderna embutida na área de trabalho, permitindo controle ágil de produtos por unidade e por peso (granel / balança).

---

## ✨ Principais Funcionalidades

- **Módulo de Vendas (PDV / Balança):** 
  - Atendimento rápido por unidade (picolés, potes, etc.) ou por peso em quilos para produtos a granel (açaí e sorvetes).
  - Suporte à leitura de códigos de barras.
- **Controle de Estoque Inteligente:**
  - Baixa automática de inventário em tempo real a cada venda concluída.
  - Alerta dinâmico de status de estoque (*Ideal*, *Estoque Baixo* e *Esgotado*).
  - Cadastro, edição e exclusão individual de produtos direto pela interface.
- **Módulo Financeiro e Notas Fiscais:**
  - Fechamento de caixa com contagem de vendas e faturamento acumulado.
  - Emissão, visualização prévia e geração de cupom fiscal em formato pronto para impressão/PDF.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas e leves para garantir alta performance e facilidade de empacotamento:

* **[Python](https://www.python.org/)** — Linguagem principal do backend e lógica do sistema.
* **[PyWebView](https://pywebview.flowrl.com/)** — Biblioteca para renderizar a interface gráfica moderna em uma janela de aplicativo desktop nativa.
* **[SQLite](https://www.sqlite.org/)** — Banco de dados relacional leve e embutido para persistência local de dados e inventário.
* **HTML5, CSS3 & JavaScript** — Construção de uma interface de usuário elegante, responsiva e com identidade visual personalizada.
